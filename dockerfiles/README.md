# iced-rs/docker

Docker images for building `iced` applications, updated to use `debian-trixie` as base image.
The docker files are taken originally from the [`iced-rs/docker`] repository.

These images can be used together with [`cross`] for cross-compilation to different
targets (e.g. Raspberry Pi).

[`cross`]: https://github.com/rust-embedded/cross
[`iced-rs/docker`]: https://github.com/iced-rs/docker/blob/6e97ba7eaf6df6194da9b2d1ef58ab33eef60ab4/README.md
